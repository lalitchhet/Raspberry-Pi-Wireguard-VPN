# Backup Workflow
Raspberry Pi---------pivpn -bk---------Backup File---------WinSCP / SCP---------Backup Computer

# Maintenance

Recommended maintenance activities include:

- Keeping the Raspberry Pi operating system updated
- Reviewing VPN client profiles
- Removing unused VPN clients
- Maintaining backup copies
- Testing remote connectivity
- Reviewing VPN diagnostics when troubleshooting
