# Project Overview

## Purpose

The purpose of this project was to build a personal WireGuard VPN using a Raspberry Pi and PiVPN.
The project was designed to provide secure remote access to the home network while building hands-on Linux, networking, and VPN administration experience.

## Platform

- Raspberry Pi
- Raspberry Pi OS Lite 32-bit
- PiVPN
- WireGuard

## Main Components

- Raspberry Pi WireGuard server
- Home router
- Internet connection
- iPhone WireGuard client
- Windows WireGuard client

## Key Functions

The completed project includes:

- SSH administration
- WireGuard VPN
- Client profile creation
- Router port forwarding
- DNS configuration
- Mobile VPN access
- Windows VPN access
- VPN diagnostics
- Configuration backup
